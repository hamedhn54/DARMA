DARMA – Definitions & Accounts module (v1)

این بسته یک ماژول مستقل برای بخش «تعاریف و حساب‌ها» است و فایل‌های داشبورد فعلی را بازنویسی نمی‌کند.

محتویات:
- src/database/definitionsDb.ts : دیتابیس محلی Dexie و مدل داده
- src/pages/DefinitionsPage.tsx : صفحه مدیریت حساب‌ها و تعاریف
- src/pages/DefinitionsPage.css : استایل صفحه

پیش‌نیاز:
- dexie
- lucide-react
این دو وابستگی در نسخه فعلی پروژه دارما نصب شده‌اند.

نصب:
1) ZIP را در ریشه پروژه DARMA استخراج کنید:
   unzip -o DARMA_definitions_v1.zip -d .
2) برای اتصال صفحه به منوی موجود، در فایل src/App.tsx این import را اضافه کنید:
   import DefinitionsPage from "./pages/DefinitionsPage";
3) در کامپوننت اصلی، state صفحه یا route فعلی را به گزینه «تعاریف» متصل کنید و هنگام انتخاب آن:
   <DefinitionsPage />
   را نمایش دهید.
   نمونه ساده:
   {activePage === "definitions" ? <DefinitionsPage /> : <Dashboard />}
4) گزینه منوی «تعاریف» باید activePage را برابر "definitions" کند.
5) در ترمینال:
   npm run dev -- --host 0.0.0.0

نکات مهم:
- چهار ریشه دارایی‌ها، بدهی‌ها، درآمدها و هزینه‌ها با شناسه ثابت seed می‌شوند و از UI قابل ویرایش/حذف نیستند.
- معین‌ها و تفصیلی‌ها در IndexedDB ذخیره می‌شوند.
- بانک/صندوق/کیف پول زیر معین ذخیره می‌شوند. فرم بانک دارای نام بانک، شماره کارت، شماره حساب، شبا و مانده اولیه اختیاری است.
- اشخاص با نام و نقش طلبکار/بدهکار ذخیره می‌شوند.
- وام قبلی با loanTiming=existing ذخیره می‌شود و affectsCashOnCreate=false دارد؛ وام فعلی با affectsCashOnCreate=true علامت‌گذاری می‌شود.
- این ماژول هنوز سند حسابداری ایجاد نمی‌کند و مانده واقعی حساب‌ها را تغییر نمی‌دهد. علامت affectsCashOnCreate صرفاً داده لازم برای اتصال بعدی به Accounting Core است. اثر مالی واقعی باید فقط از طریق سرویس حسابداری و ثبت سند دوطرفه انجام شود.
- مبالغ در ریال ذخیره می‌شوند.
- این ماژول دیتابیس جداگانه DarmaDefinitionsDB دارد تا با دیتابیس‌های احتمالی موجود تداخل نکند. در مرحله یکپارچه‌سازی نهایی، می‌توان آن را به دیتابیس مرکزی دارما منتقل کرد.
- برای جلوگیری از حذف اشتباهی، حذف یک معین همراه با همه زیرمجموعه‌های آن انجام می‌شود و تأیید کاربر می‌گیرد.
