# DARMA – اصلاحات وام‌ها و خرید اعتباری (v2)

این بسته بر پایه نسخه v1 ماژول وام‌ها و خرید اعتباری ساخته شده است.

## تغییرات
- جزئیات اقساط هر وام و خرید اعتباری به‌صورت کشویی و بسته در حالت پیش‌فرض نمایش داده می‌شود.
- دکمه «ثبت پرداخت» در صفحه وام‌ها کاربر را به فرم استاندارد پرداخت در صفحه تراکنش‌ها می‌برد.
- در فرم پرداخت تراکنش‌ها می‌توان یک قسط پرداخت‌نشده را انتخاب کرد؛ انتخاب قسط، مبلغ را از برنامه اقساط می‌گیرد و مبلغ را قفل می‌کند تا سند دفترکل با مبلغ قسط مغایرت نداشته باشد.
- پرداخت قسط از همان فرم، با حساب بانکی، تاریخ شمسی انتخاب‌شده و شرح قابل ویرایش ثبت می‌شود؛ سرویس اختصاصی قسط، بدهی و مانده نقدی را در یک تراکنش اتمیک به‌روزرسانی می‌کند.
- پرداخت‌های اقساط وام و خرید اعتباری در فهرست تراکنش‌ها نیز قابل مشاهده‌اند؛ ویرایش/ابطال عمومی برای این اسناد غیرفعال است تا ارتباطشان با برنامه اقساط خراب نشود.
- مبلغ وام و خرید اعتباری هنگام ورود با جداکننده هزارگان نمایش داده می‌شود.
- تاریخ اولین سررسید وام و خرید اعتباری با همان تقویم شمسی فرم تراکنش انتخاب می‌شود.
- برای وام قبلی، فیلد تعداد اقساط پرداخت‌شده اضافه شده است. اقساط قبلی به‌عنوان پرداخت‌شده علامت می‌خورند، بدون اینکه برایشان خروج وجه یا سند پرداخت جدید ساخته شود؛ مانده افتتاحیه بدهی فقط برابر اقساط باقی‌مانده ثبت می‌شود.
- ساختار IndexedDB تغییر نسخه نداده و هیچ جدول یا داده‌ای حذف نمی‌شود.

## نصب
در مسیر `/workspaces/DARMA` فایل‌ها را جایگزین و سپس اجرا کنید:
```bash
unzip -o DARMA_loans_credit_v2.zip -d .
npm run build
```

برای مشاهده داده‌های قبلی، توسعه و تست را روی همان origin و پورت 5173 ادامه دهید.

## بررسی
فایل‌های تغییرکرده از نظر syntax با TypeScript transpile بررسی شده‌اند. Build کامل Vite/TypeScript در این محیط اجرا نشده است؛ خروجی `npm run build` باید در Codespaces تأیید شود.
