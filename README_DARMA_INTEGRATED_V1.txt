DARMA integrated definitions module v1

این بسته شامل App.tsx یکپارچه‌شده با ماژول تعاریف و فایل‌های ماژول است.
در منوی کناری، گزینه «حساب‌ها» به «تعاریف» تغییر کرده و با انتخاب آن صفحه DefinitionsPage نمایش داده می‌شود.
داشبورد قبلی در شاخه دیگر حفظ شده است.

نصب در ریشه پروژه:
unzip -o DARMA_integrated_definitions_v1.zip -d .

سپس اگر dev server اجراست صفحه را refresh کن. اگر متوقف است:
npm run dev -- --host 0.0.0.0

نکته: این مرحله فقط صفحه تعاریف و ذخیره محلی اطلاعات آن را متصل می‌کند. ثبت سند حسابداری و تغییر مانده واقعی حساب‌ها هنوز باید در مرحله اتصال Accounting Core انجام شود.
