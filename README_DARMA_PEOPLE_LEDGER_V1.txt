DARMA - People Ledger Module V1

محتویات:
- افزودن بخش «اشخاص و مطالبات» به منوی اصلی
- پرونده مالی هر شخص و فهرست مستقل اشخاص
- ثبت قرض دادن، قرض گرفتن، دریافت بازپرداخت، پرداخت بدهی و تهاتر
- ذخیره سند حسابداری دوطرفه و کنترل تراز بودن بدهکار/بستانکار
- محاسبه مانده طلب، بدهی و خالص هر شخص از روی ردیف‌های دفتر
- جلوگیری از دریافت/پرداخت/تهاتر بیش از مانده باز

ساختار داده:
- Dexie database version 2
- journalEntries: سربرگ اسناد
- journalLines: ردیف‌های سند
- مبالغ به ریال ذخیره می‌شوند.
- نسخه قبلی دیتابیس به‌صورت migration به نسخه 2 ارتقا می‌یابد و جدول definitions حفظ می‌شود.

نصب:
فایل‌های ZIP را در ریشه مخزن DARMA استخراج و فایل‌های موجود را جایگزین کنید:
unzip -o DARMA_people_ledger_v1.zip -d .

سپس:
npm install
npm run build
npm run dev -- --host 0.0.0.0

ملاحظات نسخه:
- برای ثبت عملیات نقدی، ابتدا در بخش تعاریف حساب بانکی، صندوق یا کیف پول بسازید.
- در این نسخه ردیف طرف مقابل وجه نقد در دفتر حسابداری ثبت می‌شود؛ مانده نمایشی حساب‌های بانکی/صندوق در سایر بخش‌های برنامه هنوز به دفترکل یکپارچه نشده است.
- داشبورد و سایر ماژول‌های تراکنش همچنان داده‌های نمونه/نمایشی دارند.
- برای نسخه بعد باید موجودی حساب‌های نقد و بانک، تراکنش‌های عمومی و دفتر اشخاص از یک موتور حسابداری مشترک تغذیه شوند.
