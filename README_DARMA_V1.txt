DARMA Dashboard UI - Version 1

این بسته شامل اولین پوسته اجرایی داشبورد دارماست.
داده‌های مالی فعلاً نمایشی هستند و به پایگاه داده یا موتور حسابداری متصل نیستند.

محتویات:
- src/App.tsx
- src/App.css
- src/index.css

نحوه نصب در Codespaces:
1) فایل ZIP را در مخزن DARMA آپلود و Extract کنید.
2) سه فایل بالا را جایگزین فایل‌های فعلی در پوشه src کنید.
3) اگر dev server فعال است، صفحه مرورگر را Refresh کنید.
4) در صورت توقف سرور، در ترمینال اجرا کنید: npm run dev -- --host 0.0.0.0

نکته:
- بسته‌های موردنیاز قبلاً در پروژه نصب شده‌اند: lucide-react و recharts.
- پوسته سه حالت روشن، تیره و ترکیبی دارد.
- فونت Vazirmatn از Google Fonts بارگیری می‌شود؛ در حالت بدون اینترنت از فونت جایگزین استفاده می‌شود.
- تاریخ و اعداد فعلی نمونه نمایشی هستند و در مرحله بعد به تقویم/داده واقعی شمسی متصل خواهند شد.
